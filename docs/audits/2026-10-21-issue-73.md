# Issue #73 offline performance baseline

This historical baseline remains the reference corpus for dashboard and
OpenRouter performance comparisons. It used three cold and three warm samples
on the same host, with 500 run folders containing 24 artifacts each, one 8 MiB
developer log per run, a 10,000-file OpenRouter tree, and 1,000 Git files.

The recorded dashboard collection results were 1.821 s p50 and 2.377 s p95
cold, and 0.130 s p50 and 0.131 s p95 warm. The cold result exceeded the
provisional 2 s p95 budget; it was retained as an observation rather than a
proven regression because no same-host predecessor existed. Safety boundaries
must not be weakened to meet this budget. Repeat the corpus on the target
filesystem before treating a cold result as a regression.

The full audit record was completed offline and did not call providers,
GitHub, or other external services. Performance measurements are engineering
baselines, not an offline provider-quality gate.
