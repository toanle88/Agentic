# Coding-agent guidelines (copy to your target repository as AGENTS.md)

- Read project instructions and existing tests first.
- Work only on the assigned issue and related regression tests.
- Do not touch credentials, .env files, or deployment settings.
- Do not commit, push, modify GitHub issues, or open PRs.
- Do not weaken or delete existing tests to make a task pass.
- Avoid network access and adding dependencies without approval.
- Prefer minimal patches, clear naming, and deterministic tests.
- Report modifications, tests actually run, and remaining risks.
